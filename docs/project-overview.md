# K-Pop Photocard Collection

## 1. Project Overview

K-Pop Photocard Collection is a database-based project designed to help users manage and track their K-Pop photocard collections.

The system will allow users to store information about their photocards, organize their collection, and maintain records of photocard trades.

## 2. Project Objective

The main objective of this project is to provide an organized system for managing K-Pop photocards.

The project aims to:

- Store photocard information in a structured database.
- Help users manage their personal collection.
- Keep track of photocard trades.
- Make it easier to search and manage collection records.
- Provide a simple and organized way to maintain K-Pop photocard data.

## 3. Main Features

The planned features of the system include:

- User management
- Photocard collection management
- K-Pop artist and group information
- Photocard details and records
- Photocard trade ledger
- Search and filtering
- Database management

## 4. Technology

The project is planned to use the following technologies:

- Frontend: To be finalized by the team
- Backend: Spring Boot
- Database: MySQL
- Version Control: Git and GitHub

## 5. Project Architecture

The basic architecture of the project is:

Frontend
↓
Spring Boot Backend
↓
MySQL Database

The frontend will communicate with the Spring Boot backend through APIs. The backend will handle application logic and communicate with the MySQL database for storing and retrieving data.

## 6. Team Development Workflow

The project uses GitHub for version control and collaboration.

The basic branch structure is:

main
↓
develop
↓
feature branches

Team members will create feature branches from `develop` for their assigned work. After completing a feature, they will create a Pull Request for review before merging it into `develop`.

## 7. Expected Outcome

The expected outcome is a functional database application that provides an organized way to manage K-Pop photocard collections and their trading records.

The project will also demonstrate practical use of database management, backend development, Git, GitHub, and team-based software development.
